## 🌟 Про проєкт (Overview)

**«AETHERIA»** — це повнофункціональний, інтерактивний та динамічний 3D-проєкт на базі **Three.js**, створений за високими стандартами сучасної архітектури комп'ютерної графіки та об'єктно-орієнтованого програмування.

Дія розгортається на магічному летючому острові верховного алхіміка. Проєкт демонструє роботу з шейдерами, фізично коректними матеріалами (PBR), процедурною генерацією звуку через Web Audio API, небесними циклами зміни часу доби, оптимізованими тінями та системою алхімічних реакцій.

```

│   ├── door/                      # PBR карти дверей
│   ├── floor/                     # Текстури скель та альфа-карти

│   ├── roof/                      # Черепиця даху вежі
│   └── wall/                      # Текстури замкової цегли
└── src/
    ├── index.html                 # Головна розмітка з UI HUD
    ├── style.css                  # Glassmorphism UI дизайн
    ├── main.js                    # Точка входу та прив'язка UI до сцени
    └── Experience/
        ├── Experience.js          # Центральний Сінглтон (координатор систем)
        ├── Camera.js              # Камера + OrbitControls + GSAP плавні переходи
        ├── Renderer.js            # WebGLRenderer, PCFSoftShadowMap, ACESFilmicToneMapping
        ├── sources.js             # Реєстр ресурсів та текстур
        ├── Utils/
        │   ├── EventEmitter.js    # Шина подій (Publish/Subscribe)
        │   ├── Sizes.js           # Адаптивність, DPI та відстеження Resize
        │   ├── Time.js            # Delta-time, Elapsed time та RAF цикл
        │   ├── Resources.js       # Асинхронний TextureLoader з fallbacks
        │   ├── Debug.js           # Панель інженерного налагодження lil-gui
        │   ├── AudioManager.js    # Процедурний синтезатор звуку (Web Audio API)
        │   └── Raycaster.js       # 3D Pointer Picking (hover, click, tooltips)
        └── World/
            ├── World.js           # Оркестратор об'єктів сцени
            ├── Environment.js     # Sky шейдер, Сонце/Місяць, зміна дня/ночі, FogExp2, зірки

            ├── AlchemyCauldron.js # Казан із магічною рідиною, бульбашки, алхімічні реакції

            ├── FloatingClouds.js  # Процедурні об'ємні хмари під і навколо острова
            └── MagicalParticles.js# Світлячки та магічні спори в повітрі
```

## ⚡ Патерни проєктування (Design Patterns)

1. **Singleton (Одинак):** `Experience` реалізований як єдиний екземпляр, що забезпечує глобальний доступ до інфраструктури (сцена, рендерер, час, розміри) без спагеті-коду.
2. **Observer / EventEmitter (Спостерігач):** Делікатна шина подій зв'язує фізику, аудіо, рендеринг та HTML-інтерфейс (наприклад, клік на кристал викликає подію `alchemy.stateChange`, яка одночасно оновлює колір рідини казана, світло рун, звук дзвіночків і бейджі в інтерфейсі).
3. **Component Architecture:** Кожен візуальний та логічний елемент світу (`Island`, `AlchemistTower`, `Waterfall`, `MagicCrystals` тощо) є ізольованим класом зі своїми життєвими циклами `setMaterials()`, `setMesh()`, `update()`.
4. **Clean Disposal:** Метод `experience.destroy()` гарантує звільнення пам'яті GPU, знищуючи геометрії, матеріали, текстури та події при завершенні роботи.

## ✨ Інтерактивність та динамічні можливості

1. **Інтерактивна алхімія кристалів:**
   - 4 стихійні кристали (🔥 **Ignis**, 💧 **Aquas**, 🌿 **Terra**, 🔮 **Aether**).
   - Клік на кристали (в 3D-просторі через Raycaster або через UI) активує світлові промені Безьє, які живлять казан.
   - Змішування різних елементів створює унікальні еліксири:
     - *Ignis + Aquas* = Містичний Пар (Mystic Vapor)
     - *Ignis + Terra* = Магматична настойка (Molten Magma)
     - *Aquas + Terra* = Еліксир життя (Elixir of Life)
     - *Всі 4 елементи* = **Філософський камінь (The Philosopher's Resonance)** з райдужним хроматичним світінням!
   - Клік на казан розмішує зілля, створюючи звукові та візуальні сплески.

2. **Небесний динамічний цикл (День / Ніч):**
   - Розрахунок сферичних координат сонця через тригонометрію.
   - Реалістичний шейдер неба `three/addons/objects/Sky.js`.
   - Динамічне сонячне/місячне світло з м'якими тінями (`PCFSoftShadowMap`).
   - Автоматична синхронізація туману `FogExp2` з лінією горизонту.
   - 1800 зірок, що запалюються вночі.
   - Швидкі пресети часу доби: 🌅 Ранок, ☀️ Полудень, 🌇 Захід, 🌙 Ніч.

3. **Процедурне аудіо без зовнішніх MP3:**
   - Повний синтез звуку на чистому **Web Audio API**:
     - Рожевий шум для гірського вітру.
     - Дзвін кристалів за гармонійними частотами Сольфеджіо (528Hz, 639Hz, 432Hz, 852Hz).
     - Звуки бульбашок казана та алхімічні акордові спалахи.

4. **Плавна кінематографічна камера (GSAP):**
   - Огляд острова (Overview).
   - Вежа алхіміка (Tower).
   - Алхімічний казан і руни (Crucible & Runes).
   - Край водоспаду (Sky Waterfall).
   - Режим автообертання (Cinematic Orbit).

5. **Інженерна панель налагодження lil-gui:**
   - Гаряча клавіша `H` або кнопка `⚙️ Controls` відкриває панель із детальними налаштуваннями світла, часу доби, туману, швидкості тощо.

## 🚀 Встановлення та запуск

### 1. Встановлення залежностей:
```bash
npm install
```

### 2. Запуск локального сервера розробки:
```bash
npm run dev
```
Відкрийте у браузері: `http://localhost:5173/`

### 3. Збірка для production:
```bash
npm run build
```
Готові оптимізовані файли будуть створені в папці `dist/`.
